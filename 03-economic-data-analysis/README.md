# Economic Data Analysis

A reproducible mini-analysis of a **synthetic** macroeconomic dataset.

## Questions
- How do growth and inflation evolve over time?
- What is the average growth rate?
- What is the correlation between inflation and the synthetic policy-rate series?
- Which years contain the largest deviations from average growth?

## Run
```bash
python src/analyze.py data/synthetic_macro.csv
```

The dataset is deliberately synthetic so the repository can remain public without licensing or provenance ambiguity.
